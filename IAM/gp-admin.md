## Purpose
The GP Admin department oversees all Global Power systems, user access and IAM governance. This role ensures systems integrity, manages AWS accounts, and maintains operational security across OSS and BSS environments.


## Core Permissions

-Full read/write access across OSS and BSS systems
-Ability to create, modify, and delete IAM roles and policies
-Access to AWS account management, billing, and security dashboard
-Oversight permissions for compliance, audits, and system integrity

## Responsibilities
-Maintain IAM policies and enforce access control across all systems
-Oversee AWS account configuration, billing, and security compliance
-Approve new user roles and manage credential lifecycle
-Conduct quarterly audits and coordinate with GP Compliance for reviews
